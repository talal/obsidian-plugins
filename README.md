# Obsidian Plugins

> [!WARNING]
> I created these plugins for personal use, without any intention of supporting end-users. I am releasing this code for educational purposes. Feel free to fork and make your own changes :)

## Plugins

| Name       | Description                                                                 |
| ---------- | --------------------------------------------------------------------------- |
| Anki Sync  | Sync flashcards written in plain markdown to Anki.                          |
| Formatter  | Format notes using a fast Rust-based formatter on file save.                |
| Typst Math | Render Typst math via MathML, i.e. use Typst Math syntax instead of MathJax |
