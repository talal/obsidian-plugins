# Obsidian Plugins

> [!WARNING]
> I created these plugins for personal use, without any intention of supporting end-users. I am releasing this code for educational purposes. Feel free to fork and make your own changes :)

## Plugins

| Name                             | Description                                     |
| -------------------------------- | ----------------------------------------------- |
| [Flashcards](plugins/flashcards) | Spaced repetition flashcards powered by FSRS-6. |
| [Formatter](plugins/formatter)   | Format notes using a fast Rust-based formatter. |
| [Typst Math](plugins/typst-math) | Write math using Typst instead of LaTeX.        |
